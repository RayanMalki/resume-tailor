# Jake's Resume Format Guide (Local)

This project uses a Jake's Resume-style layout for LaTeX output.

Conventions
- One-column layout with compact section headers.
- Section order: Education, Experience, Projects, Skills.
- Bullet points are short, impact-focused, and consistent.
- Use clear role titles, company/project names, and dates.
- Keep spacing tight and avoid verbose paragraphs.

Note: The LLM is instructed to output ONLY LaTeX without fences or commentary.
