# BM25 Signals (v1)

High-level computation
- Tokenize resume and job text by lowercasing, splitting on non-letters/digits, dropping short tokens (<2), and filtering a small built-in stopword list.
- Treat job text as the query and the resume as the document.
- Compute overall BM25 similarity and per-term signals.

Signals produced
- `top_job_terms`: BM25 contribution for top-scoring job terms against the resume.
- `missing_job_terms`: important job terms not present in the resume (ranked by IDF * term frequency).
- `overlap_terms`: unique terms appearing in both resume and job.
- `score`: overall BM25 similarity score.

Example `bm25_signals` JSON
```json
{
  "top_job_terms": [
    {"term": "kubernetes", "score": 0.55},
    {"term": "docker", "score": 0.42}
  ],
  "missing_job_terms": [
    {"term": "kubernetes", "score": 1.39}
  ],
  "overlap_terms": ["docker", "go"],
  "score": 1.02
}
```
